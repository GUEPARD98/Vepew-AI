Como experto en ciberseguridad, diseña, documenta y desarrolla la herramienta defensiva VPEW-AI (Vigilancia Proactiva para Endpoints Windows con IA). El objetivo es crear un sistema de protección avanzada para 500 endpoints Windows (Windows 10/11 y Server 2016–2019), siguiendo la mentalidad ofensiva de un hacker (fase por fase) y transformándola en controles defensivos.

El entregable debe ser un proyecto de software modular en Python (con C/C++ para partes críticas), con arquitectura clara, pseudocódigo funcional, librerías necesarias y plan de despliegue.

Descripción de la herramienta VPEW-AI.

Objetivos principales de protección.

Principios de seguridad aplicados (Planificar, Prevenir, Detectar, Responder, Repetir).

2) Tabla de Fases de Ataque → Indicadores Defensivos

Construir tabla de fases (Reconocimiento, Acceso, Persistencia, Movimiento Lateral, Cleanup).

Para cada fase: objetivo del atacante, indicadores defensivos de VPEW-AI y fuentes de telemetría.

3) Arquitectura Modular y Comunicación Segura

Componentes: Sensor, Backend (SOF-ELK), Motor de Reglas/ML, Consola de Gestión.

Comunicación TLS 1.2+ con mTLS y PKI.

4) Lenguajes y Librerías Windows/ML

Python como base.

C/C++ para integración de bajo nivel.

Librerías: Win32 API, WMI, psutil, TensorFlow/Keras, Scikit-Learn, PyParsing, logging.

IDs relevantes: 4624, 4625, 4697, 1102.

Sysmon (eventos 1 y 3).

ETW para bajo overhead.

Integración con SOF-ELK o SIEM corporativo.

6) Reglas Sigma Conceptuales (5 Reglas)

R2: Acceso a SAM/LSASS (extracción de credenciales).

R3: Integridad de binarios críticos.

R4: Conexión saliente C2.

R5: Intentos de autenticación masivos contra cuentas deshabilitadas.

Inicialización del agente con validación legal/ética.

Recolección de eventos → features → tensores NumPy.

8) Plan de Pruebas (8 Casos) + Playbooks de Respuesta (3)

Casos P1–P8 para validar detección (escaneo, extracción credenciales, persistencia, evasión, hardening, borrado logs, validación controles, evasión blackbox).

Violación de integridad binaria.

Extracción de credenciales.

Barrido/reconocimiento anómalo.

9) Métricas de Calidad

Latencia de detección < 2s.

Retención de logs > 90 días.

Falsos positivos < 1%.

Cobertura mínima de MITRE ATT&CK: 80%.

10) Roadmap de Despliegue

Laboratorio y hardening (4 semanas).

Piloto en 20 endpoints (6 semanas).

Producción en 480 endpoints (8 semanas).

Operación continua (mejora trimestral, reentrenamiento ML).
